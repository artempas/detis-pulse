# Индексация страницы #пульсуй в Google и Яндексе

Страница: **https://detis.ru/puls/**

Что уже сделано в коде (Часть A) и что осталось сделать команде фонда (Часть B).

---

## Часть A — сделано в этом репозитории

| Что | Где |
|---|---|
| `canonical`, `robots`, `theme-color` | `index.html`, `<head>` |
| Open Graph + Twitter Card (превью для соцсетей и поиска) | `index.html`, `<head>` |
| Структурированные данные Schema.org (`NGO`, `WebPage`, `WebSite`, `Event`) | `index.html`, `<script type="application/ld+json">` |
| Текстовый `<h1>` для поисковика (скрыт визуально, картинка осталась) | `index.html`, `.hero__title` |
| `sitemap.xml` — карта из одной страницы | корень репозитория → публикуется как `https://detis.ru/puls/sitemap.xml` |
| `robots.txt` — образец (рабочий нужен в корне домена, см. B1) | корень репозитория |
| `assets/favicon.svg` | иконка вкладки |

### Осталось по коду (нужны бинарные файлы от дизайнера)

1. **`assets/og-image.jpg`** — превью **1200×630 px**, JP/PNG до ~1 МБ.
   Логотип/надпись `#пульсуй` + фон в фирменных цветах (`#bf2c23`).
   Без картинки соцсети и поисковая выдача покажут страницу без изображения.
2. **`assets/favicon.ico`** (16/32/48) и **`assets/apple-touch-icon.png`** (180×180) —
   по желанию, можно сгенерировать из `assets/ds_logo.png`
   (например realfavicongenerator.net). После добавления — раскомментировать
   соответствующие строки `<link rel="icon">` в `index.html`.

### Важно про адрес

Все ссылки в мета-тегах и файлах используют **`https://detis.ru/puls/` со слешом на конце**.
Относительные пути (`styles.css`, `script.js`, `assets/...`) работают только если страница
открывается по адресу с завершающим слешем. Нужно, чтобы сервер отдавал страницу по
`/puls/` и делал **301-редирект с `/puls` на `/puls/`**.

Если итоговый адрес будет другим — заменить `https://detis.ru/puls/` во всех местах:
`index.html` (head + JSON-LD), `sitemap.xml`, `robots.txt`.

## Часть B — действия команды фонда

### B1. robots.txt и sitemap на detis.ru
- [ ] Открыть `https://detis.ru/robots.txt`, убедиться, что нет `Disallow: /puls`.
- [ ] Добавить строку `Sitemap: https://detis.ru/puls/sitemap.xml`
      (или внести URL страницы в основной sitemap сайта).
- [ ] Проверить: `https://detis.ru/puls/` отдаёт код 200 по HTTPS,
      `https://detis.ru/puls` делает 301 на версию со слешем.

### B2. Google Search Console — https://search.google.com/search-console
- [ ] Проверить, добавлен ли ресурс `detis.ru`. Если да — доступ к `/puls/` уже есть.
- [ ] Если нет — добавить ресурс и подтвердить владение (мета-тег `google-site-verification`
      → вставить в `index.html` рядом с другими мета и раскомментировать, либо загрузить
      HTML-файл подтверждения в корень сайта).
- [ ] **Проверка URL** → `https://detis.ru/puls/` → **Запросить индексирование**.
- [ ] **Файлы Sitemap** → добавить `https://detis.ru/puls/sitemap.xml`.

### B3. Яндекс.Вебмастер — https://webmaster.yandex.ru
- [ ] Проверить, добавлен ли сайт `detis.ru`.
- [ ] Если добавляем заново — подтвердить мета-тегом `yandex-verification`
      (вставить в `index.html`, раскомментировать).
- [ ] **Индексирование → Переобход страниц** → добавить `https://detis.ru/puls/`.
- [ ] **Индексирование → Файлы Sitemap** → добавить адрес карты.
- [ ] **Инструменты → Валидатор микроразметки** — проверить страницу, 0 ошибок.

### B4. Ссылки на страницу (ускоряет попадание в индекс)
- [ ] Поставить ссылку на `https://detis.ru/puls/` с detis.ru: блок акций на главной,
      новость о запуске флешмоба, меню или подвал. Ссылка с проиндексированного сайта —
      самый быстрый способ, чтобы робот нашёл страницу.
- [ ] Анонс со ссылкой в VK, Telegram (`t.me/detis_ru`), OK.

## Проверка результата

1. **Микроразметка**: https://validator.schema.org и
   https://search.google.com/test/rich-results — вставить URL или HTML, 0 ошибок.
2. **Превью в соцсетях** (после деплоя и добавления `og-image.jpg`):
   - Telegram — написать боту `@WebpageBot`;
   - VK — https://vk.com/dev/pages.clearCache;
   - общий предпросмотр — https://www.opengraph.xyz.
3. **Sitemap**: https://www.xml-sitemaps.com/validate-xml-sitemap.html
4. **Через 3–14 дней**: запрос `site:detis.ru/puls` в Google и Яндексе показывает страницу;
   в Search Console / Вебмастере статус — «Проиндексировано».

## Что НЕ входит

- Платная реклама / контекст.
- Пережатие тяжёлых картинок (`assets/img12.png` ~700 КБ) — на индексацию влияет слабо,
  можно сделать позже для скорости загрузки.
